Help a Spanish-speaking holder stay in control.

Confirm a narrow mandate in Spanish, inspect the representative’s request in English, then decide what the advocate may relay. The original policy and holder-decision code enforce the result.

This demo uses fixed fictional scenarios. It contacts no institution, discloses no personal data, and performs no external action. Temporary authorization records are deleted after each run.
